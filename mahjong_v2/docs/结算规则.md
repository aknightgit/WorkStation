# 长清阁麻将 - 点数结算规则

## 一、固定点数牌型（直接使用固定值）

| 牌型 | 点数 |
|------|------|
| 清一色 | 10点 |
| 风一色 | 20点 |
| 风碰 | 40点 |
| 无花自摸 | 10点 |
| 杠开 | 10点 |

---

## 二、公式计算牌型

```
基础点数 = 2 + 花牌数 + 组合牌点数
```

### 组合牌点数
| 类型 | 点数 |
|------|------|
| 风牌刻子 | 1点 |
| 箭牌刻子 | 2点 |
| 风牌杠 | 2点 |
| 箭牌杠 | 3点 |
| 其他牌杠 | 1点 |
| 暗杠 | 在上述基础上 +1点 |

---

## 三、额外翻倍（可叠加）

| 条件 | 倍数 |
|------|------|
| 无百搭 | ×2 |
| 门清 | ×2 |

**最终点数 = 基础点数 × 翻倍系数**

---

## 四、特殊规则

### 血战到底
- 一家胡牌后继续，另外三家继续战斗
- 三家全部胡牌或牌墙摸完 → 结算
- 最后胡牌者 ×1.5

### 造反
- 满足条件可选择造反
- 成功 → 下局倍数 ×2
- 失败 → 正常结算

### 流局翻倍
- 流局 → 下局倍数 ×2
- 最高封顶 ×8

### 包三家/四家
- 吃/碰另一方三口 → 赔付 ×3
- 吃/碰另一方四口 → 赔付 ×5
