## 三、公式

```
最终分数 = 基础分 × 2^(总番数-1) × 全局倍数

其中：
- 总番数 = 牌型番 + 特殊番 + 过程番
- 全局倍数 = 初始1 × 2^(造反次数) × (流局叠加)
- 最高封顶 256 番
```

---

## 四、特殊规则

### 1. 血战到底
- 第一家胡牌后继续，三家胡牌或牌墙摸完结束
- 未胡三家分别扣分给胡牌者
- 最后胡牌者分数 ×1.5

### 2. 造反
- 满足五毒散牌型可选择造反
- 造反成功 → 下局全局倍数 ×2（最高8）
- 造反失败 → 正常结算

### 3. 包三家/四家
- 连续三家/四家未胡，最后一家全包

## 五、代码实现要点

```dart
// 计算总番数
int calculateFan(List<Tile> hand, Map<String, bool> info) {
  int fan = 0;
  
  // 牌型番
  if (info['menqing']) fan += 1;
  if (info['duidui']) fan += 2;
  if (info['hys']) fan += 3;
  if (info['qys']) fan += 6;
  if (info['qidui']) fan += 8;
  if (info['13ys']) fan += 12;
  
  // 特殊番
  if (info['tianhu']) fan += 16;
  if (info['dihu']) fan += 16;
  
  // 过程番
  if (info['zimo']) fan += 1;
  if (info['qianggang']) fan += 1;
  if (info['gangshanghua']) fan += 2;
  
  return fan.clamp(1, 256);
}

// 计算最终分数
int calculateScore(int base, int fan, int multiplier) {
  int score = base;
  for (int i = 1; i < fan; i++) {
    score *= 2;
  }
  return score * multiplier;
}
```
